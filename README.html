Surface

Surface owns the surface; the runtime borrows the fabric.

A locked prompt dock and a generative, composable, persistent canvas that any agent CLI drives to paint a glanceable operator console. Think LSP for agent consoles: Surface is the editor, each agent CLI is a language server, capability negotiation lights up features. The kernel owns the surface and the protocol; agents, memory, and orchestration are borrowed from the runtime through an adapter.

Get started View on GitHub
host.mjs 
import { createSurface } from "@selfworking-ai/surface";
import { echoAdapter } from "@selfworking-ai/surface/adapters/echo.mjs";

const surface = createSurface({ adapter: echoAdapter(), port: 5757 });
const { url } = await surface.listen();
console.log(`Surface live at ${url}`);
Or just npx surface dev — boots a Surface with the echo adapter (or your surface.config.js).
The kernel

A surface, not a transcript

Retained-mode canvas

The agent patches, not repaints

Composition lives in a durable workspace document. The agent sends mount / update / remove / layout ops; a tiny reconciler diffs by component id and applies them. The canvas is composable and persistent — never a scroll log.

Locked dock

One trusted input

The kernel's syscall interface. Locked for UX and security — it is what makes visitor mode safe.

Protocol

Versioned + negotiated

Every wire message carries a version. Host/runtime mismatches degrade gracefully instead of corrupting state.

Capability tiers

A · B · C

The kernel lights up org affordances by what the adapter advertises, and quietly hides the rest.

Persistence

File store by default

Frames + workspace persist as JSONL on disk. Swap the StorageProvider behind a kernel port.

Design system Tokens only

visionOS glass, four rings

Tokens → primitives → composed → packs, each ring constraining the one above. This very page is rendered in those tokens. Registration rejects non-token values.

Scope

What it is, and is not

Surface is

  • A kernel: locked dock + retained-mode canvas + registry + broker + identity boundary + the protocol.
  • Runtime-agnostic — any agent CLI drives it through an adapter.
  • Embeddable in ~10 lines via createSurface.
  • Zero-build — vanilla ESM, one runtime dep (ws), tests on node:test.

Surface is not

  • Not an agent platform — no agent logic, orchestration, memory, or spawning; those are borrowed.
  • Not a chat transcript — the canvas is retained-mode and composable.
  • Not an API-key app — auth flows through the local agent-CLI credentials.
  • Not public-by-default — loopback bind + WS origin allowlist, always.

Identity & auth status. The identity/permission boundary is the kernel contract — provider ports, the containment grant rule, the audit anchor, a config-gated Google OIDC builder, and a mock-tested identity plane all ship. The end-to-end auth flow is not yet operable: there is no HTTP /auth route or connection↔principal binding, the WebAuthn verifier intentionally throws (signature crypto is a deferred vetted island), and OIDC has not been exercised against live Google. Surface runs single-operator on loopback today; multi-tenant authentication is architecture, not a login.
